## 2. 键盘与焦点

- 页面提供“跳到主要内容”链接和 `#main-content`；
- 本地/联网模式使用 `aria-pressed` 语义按钮；
- 记录抽屉打开后焦点进入关闭按钮，关闭后返回原“牌局记录”按钮；
- 按钮、链接、输入框和选择框均有清晰 `focus-visible` 轮廓；
- 记录抽屉支持 Escape 关闭。

## 3. 触控与动态效果

- 520px 以下主要按钮最小高度为 44px；
- 手牌按钮在移动端保留 47px 高度并支持横向滚动；
- `prefers-reduced-motion: reduce` 下动画和过渡缩短至近乎即时；
- `forced-colors` 模式为牌、玩家区和面板保留系统边框。

## 4. 错误与网络恢复

- React 根节点使用错误边界，异常时不输出牌局/令牌数据；
- 回退页面说明本地存档仍保留并提供重新载入；
- 联网连接显示连接中、在线、断线重试和错误状态；
- 实测停止 WebSocket 服务后出现断线/连接错误提示；
- 服务恢复后客户端自动重连，控制台无新增错误。
