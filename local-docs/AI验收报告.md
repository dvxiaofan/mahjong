# M3 AI 验收报告

- **验收日期**：2026-09-05
- **范围**：合法动作代理、手牌评估、出牌策略、碰杠/报嘴策略、难度与批量模拟
- **结论**：M3 验收通过

## 1. 功能结果

- AI 的每个动作都必须通过 `getLegalActions()` 边界；
- 策略返回非法动作、空动作或抛出异常时，代理会采用阶段安全回退；
- 手牌评估包含标准向听、有效进张、公开可见剩余张数、清一色与碰碰胡潜力；
- 评估只读取本座暗手和桌面公开信息，修改对手暗手不会改变结果；
- 出牌选择包含评分、原因和备选方案，可在牌局回放中查看；
- 胡牌、报嘴、碰、明杠、暗杠和补杠均有明确策略；
- 休闲、标准、进阶三档难度使用确定性随机源，可复现。

## 2. 批量整局结果

|---|---:|---:|---:|---:|---:|---:|---:|
| 休闲 | 4100 | 5/5 | 0 | 5 | 334.2 | 11.28% | 0 |
| 标准 | 5100 | 5/5 | 4 | 1 | 277.8 | 91.79% | 0 |

这些结果用于验证稳定性和行为差异，不作为长期胜率平衡结论。样本较小，且四座位使用相同档位。

## 4. 复现方式

```bash

npm run simulate:ai -- --games=5 --seed=5100 --difficulty=standard

```

支持的难度值：`casual`、`standard`、`advanced`。

## 5. 已知边界

- 当前 AI 是可解释启发式策略，不是机器学习模型；
- 休闲档故意允许较弱选择，因此荒庄率可能显著高于另外两档；
- 风险评估仅使用公开牌，不推断对手隐藏手牌；
- 长期平衡性需要在多局会话和更大样本统计完成后继续校准。
