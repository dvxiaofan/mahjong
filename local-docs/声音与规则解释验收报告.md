## 1. 已实现行为

| 入口                   | 行为                                                       | 边界                                                 |
| ---------------------- | ---------------------------------------------------------- | ---------------------------------------------------- |
| 页头“开启声音”         | 公开出牌报牌，碰、各类杠、报嘴、发财、胡牌、自摸与荒庄播报 | 默认静音；暗手、私有摸牌和听口不读出                 |
| 页头“声音设置”         | 语音/音效独立开关、音量、试听和本地保存                    | 刷新后等待首次操作恢复；存储失败仍可调整             |
| 胡牌结算下方           | 四组面子和一对将牌，标明顺子、刻子、碰及三类杠             | 使用实际手牌，每张实体牌只计一次；优先匹配碰碰胡番种 |
| 我方操作下方“胡牌条件” | 当前资格、阶段原因、发财条件、锁定听口和可展开的牌型整理   | 默认收起；仅计算自己的已知牌；观战不提供私有分析     |

“胡牌条件”区分未成牌、无发财、未报嘴、非锁定听口、尚未摸牌、待补牌、碰后出牌、他人回合、自己弃牌及已经响应。规则资格和回放、提交中、断线等操作状态分别说明。没有新增动作入口，最终合法操作仍由原规则引擎生成。

截图中的 `45677万、566778筒、389条` 会显示三、八、九条为未成组牌；三条换成七条后，可整理为四组顺子和七万将牌。部分整理仅是一种搭配，不能用于宣告胡牌。

## 2. 规则与隐私实现

- [rules.ts](../src/rules.ts) 的 `getWinBlockReason()` 同时供原有自摸/接炮布尔判断和前端解释使用。
- `getWinningHandGroups()` 和 `getHandArrangement()` 复用同一组牌搜索；后者只在展开帮助时允许保留未成组牌，严格胡牌路径仍要求四面子一将和实体四张上限。
- [winExplanation.ts](../web/winExplanation.ts) 只读取座位投影中的自身牌与公开弃牌，不读取完整牌局、对手暗手或对手听口。
- 回放虽然移除了合法动作，仍可解释历史局面；[WinHelp.tsx](../web/components/WinHelp.tsx) 不提交动作，终局由结算分组承接。
- 声音只通过新增公开事件的固定类型与牌值选取资源，不把事件文字交给朗读器；初始快照、回放、重连、新局和身份切换不重放历史。
- 静音、后台和新事件会清理过期播放；异步加载/解码也检查代次，两路音频独立取消。声音失败不改变牌局状态。

## 3. 音频资源维护

女声包为 38 段普通话 MP3，总计 143,752 字节，单段约 0.22–0.49 秒。来源为本机 macOS `say` 的 Tingting 普通话音色，语速 195，使用 FFmpeg 裁切静音并转换为 24 kHz 单声道、64 kbps。清单和文本保存在 [manifest.json](../web/public/audio/mandarin/manifest.json)。

男声包同样为 38 段，约 220 KB，使用 Piper 1.8 的 `zh_CN-chaowen-medium` 离线神经语音生成（模型基于 CC0 中文语音数据训练），长度系数 0.85，再经 FFmpeg 裁切、响度归一化和同样的 24 kHz 单声道转码。清单在 [mandarin-male/manifest.json](../web/public/audio/mandarin-male/manifest.json)。两套包都由前端直接加载，运行时没有在线语音服务、账号或 API Key；声音设置可切换男声/女声，默认男声。

三段牌桌音效由 [generate-sound-effects.mjs](../scripts/generate-sound-effects.mjs) 合成，分别用于出牌、普通动作和胡牌。声音偏好键为 `play-mahjong.sound.v1`；首次默认静音，两路开关默认开启，语音/音效音量分别为 80% / 35%。

仅在维护音频时运行：

```bash
node scripts/generate-voice.mjs          # 女声：macOS Tingting + ffmpeg
node scripts/generate-sound-effects.mjs # Node.js
```

男声包由 Piper 模型离线生成后提交，仓库不包含 63 MB 的 ONNX 模型。替换已发布声音后同步更新 [tableAudio.ts](../web/tableAudio.ts) 中的 `AUDIO_VERSION`，并逐段检查发音、音量、解码和连续动作的取消行为。当前 URL 版本为 `v=2`，用于避开旧版浏览器缓存。
