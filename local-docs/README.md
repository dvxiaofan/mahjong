# GPT 分析文档

本目录用于存放 Codex（GPT）根据项目讨论整理的分析、需求和设计文档，不作为麻将规则原文。

## 文档索引

- [游戏需求文档](./游戏需求文档.md)：项目可行性、开发分期、技术方案、状态机、AI、UI、测试和待确认事项。
- [补充建议](./补充建议.md)（GLM，2026-09-04）：现存规则冲突、测试缺口、联机设计缺口与过时内容对照。
- [开发实施计划](./开发实施计划.md)：分阶段实施步骤、每步验收标准、状态标记、决策台账和进度日志。
- [AI 验收报告](./AI验收报告.md)：M3 策略能力、批量整局数据、复现命令和已知边界。
- [联网消息协议](./联网协议.md)：协议版本、消息类型、隐私边界、修订号和幂等规则。
- [最终麻将规则](../自定义麻将规则.md)：项目实现时应遵循的规则原文，不在本目录内。

## 使用约定

- 规则变更先更新上级目录的《自定义麻将规则.md》；
- 产品、技术和实现分析放在本目录；
- 文档中的“待确认”事项在规则确认后应回写到需求文档；
- 本目录中的文档属于分析稿，不能替代规则定稿。
