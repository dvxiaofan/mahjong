## 使用约定

- 规则变更先更新上级目录的《自定义麻将规则.md》；
- 产品、技术和实现分析放在本目录；
- 外部麻将方案只用于 UI 设计参考；规则、合法动作、计分与状态推进保持本项目独立实现，调研建议与已实现需求分开维护；
- 用户反馈由用户和开发协作者共同维护在《问题记录.md》中，保留原意和编号，并与实施计划同步处理状态；
- 文档中的“待确认”事项在规则确认后应回写到需求文档；
- 本目录中的文档属于分析稿，不能替代规则定稿。
