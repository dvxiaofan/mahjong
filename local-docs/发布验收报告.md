## 3. 启动冒烟

使用干净构建后的 `npm start` 在独立端口启动成功：

- `/healthz` 返回 HTTP 200、`status: ok`、协议版本和房间数；
- `/readyz` 使用同一只读健康结构；
- `/` 返回构建后的中文页面；
- 响应包含 CSP、`X-Frame-Options: DENY`、`nosniff`、无 referrer 和 COOP；
- HTML/SPA 路径使用 `no-cache`，哈希静态资源允许缓存；
- WebSocket、广播、断线恢复和状态文件重启恢复由真实连接测试覆盖。

## 4. 容器配置

- `docker compose config --quiet` 通过；
- 多阶段 Dockerfile 使用 Node 22 Alpine、非 root `node` 用户、持久化 `/app/data` 卷和健康检查；
- 镜像构建阶段执行检查、测试和生产构建；
- 本机 Docker CLI 可用，但 Docker daemon 未启动，`docker build` 未能在本机实际执行；
- 容器配置应在已启用 Docker 的 CI/部署机上执行 `docker compose up --build` 作为发布前最后一步。
