# 学习、约局与教练复盘验收报告

- **验收日期**：2026-11-15
- **范围**：R-04 自有规则短教程、R-06 约局入口、R-05 关键节点复盘、Playwright E2E、教练 2.0 整局点评
- **结论**：五项全部完成。教程和复盘复用真实规则动作；约局邀请不泄露密码或恢复令牌；整局教练只分析本家人类出牌；自动化和 PC 浏览器验收通过。

## 一、实现范围

### R-04 自有规则短教程

- `web/tutorial/scenarios.ts` 提供四课：发财补牌、零财不能接炮、三财先报嘴、杠后补牌。
- 每一步都从真实 `GameState` 调用 `getLegalActions()` 和 `applyAction()`，目标动作不合法时不推进。
- `web/tutorial/TutorialMode.tsx` 在牌桌右栏展示步骤、成功反馈、重玩、下一课和课程切换。
- 页头新增“规则教程”，本地开局新增“先学规则”；教程不读写普通本地对局存档。

### R-06 约局入口

- `web/online/invite.ts` 把房间状态映射为四个座位：空位、在线、离线、机器人、托管中。
- 邀请地址使用 `?mode=online&room=<房间名>`，打开后自动进入联网模式并预填房间名。
- 邀请文本只包含房主、人数和入口；有密码时提示另行索取，不包含密码或恢复令牌。
- `web/online/RoomInvitePanel.tsx` 显示四座状态和复制按钮；剪贴板不可用时选中文本供手动复制。

### R-05 关键节点复盘

- `web/replayMarkers.ts` 标记报嘴、碰、明杠、暗杠、补杠与胡牌。
- 节点直接使用 `RecordedAction` 的 1-based 索引生成 `beforeStep` / `afterStep`，没有用事件序号冒充动作步数。
- 牌局记录新增“关键节点”区，可跳到动作前或动作后；记录抽屉在 PC 宽屏加宽到 560px，关键节点字号提升到 11–13px。

### Playwright E2E

- `e2e/tutorial-local.spec.ts`：教程真实动作推进、本地开局、打开牌局记录。
- `e2e/online-invite.spec.ts`：双浏览器创建房间、邀请深链、加入、补两个机器人、房主开局。
- `e2e/coach-review.spec.ts`：注入 264 步终局牌谱，验证“继续对局”、整局点评、反馈、关键节点与回放跳转。
- `e2e/fixtures/completed-local-session.json`：种子 1、庄家 0、264 个合法动作、15 次本家人类出牌、8 次碰、1 次暗杠、1 次报嘴、1 次胡牌。
- `web/localSession.fixture.test.ts` 逐动作回放固定牌谱，防止 fixture 静默失效。

### 教练 2.0 整局点评

- `web/coach/gameReview.ts` 只统计 `source === 'human'` 的本家出牌，分类为和教练一致、更稳、可改进、放炮。
- 放炮归因读取真实待响应弃牌的 `discarder` 与牌面，不再仅按相同牌面猜测。
- 终局显示出牌次数、分类统计、平均放炮风险和最值得复盘的前三手。
- `web/coach/coachFeedback.ts` 只保存难度、评价、整局统计和时间，不保存手牌、牌山或恢复令牌；支持导出本地 JSON 样本。

## 三、PC 浏览器视觉复核

使用 1280×900、1440×1000、2000×1200 三档检查教程、终局点评、牌局记录和联网约局：

- 教程工具栏、四课 Tab、右栏步骤卡和手牌区不重叠，无页面横向滚动。
- 终局教练卡在右栏顶部完整显示，综述和前三手在 1280/1440/2000 下均可读，未遮挡结算与四家亮牌。
- 牌局记录抽屉使用不透明深底，关键节点、跳转按钮和事件列表层级清楚。
- 约局面板四座横排，在 2000px 下利用整行宽度；空位、在线、机器人和托管均有文字标签。
- 新增界面正文不低于 11px，主要信息为 12–13px；没有把按钮或展开内容放到手牌下方。

## 四、边界与后续

- 教练概率只基于当前 AI 难度与 `GameView` 公开信息，不宣称对真人打法准确。
- 教程使用独立临时状态，不影响普通存档；关键节点只改变回放查看位置，不修改实时牌局。
- R-07 声音细节评估仍暂停；本轮没有改动声音文件、规则引擎或联网协议。
