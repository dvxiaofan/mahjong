# 嗨！搓麻呀！ (play-mahjong)

一套自约定玩法的麻将游戏。暂无地区名称，规则由牌友口约定稿，本仓库为其数字实现。

## 玩法速览

- **120 张牌**：万 / 筒 / 条各 36 张，红中、发财、白板各 4 张；无风牌、无花牌
- **发财是宝牌**：摸到即亮出，从墙尾补一张；每张 +1 番，不能碰、不能杠、不入牌型
- **禁吃**，三家通碰，无抢杠胡
- **3 番种可叠加**：碰碰胡 +1、清一色 +1、发财每张 +1
- **报嘴**（固定听口）：≥3 财听牌可自愿报嘴锁定听口，换来自摸、点炮全解锁
- 荒庄杠分一律作废（含已付的补杠分）
- 首局四家掷骰比总点定庄，并列者加赛；后续赢家接庄，荒庄默认留庄

完整规则见 [自定义麻将规则.md](./自定义麻将规则.md)。

## 开发

```bash
npm install        # 安装依赖
npm run dev        # 启动本地牌桌页面
npm run check      # TypeScript 类型检查
npm test           # 运行全部测试
npm run coverage   # 测试并生成覆盖率报告
npm run quality    # 运行提交/CI 前全部质量门禁
npm run test:e2e   # 运行教程、约局与终局复盘浏览器测试
npm run build      # 编译引擎、页面和 WebSocket 服务
npm start          # 启动页面和 WebSocket 服务（默认 8787）
```

首次运行 E2E 前执行 `npx playwright install chromium`。本机若已有 Chrome，也可用
`PLAYWRIGHT_CHANNEL=chrome npm run test:e2e` 免下载 Chromium。

## 声音与胡牌说明

- 手机默认先选牌，再按“打出”确认；“手牌设置”可切换直接出牌与单行滚动，偏好会保存在本设备。
- 我方操作区集中显示当前主提示，响应按钮位置固定；定庄详情、响应进度与牌局动态可按需展开。
- 页头点击“开启声音”即可听公开出牌和碰杠胡播报；“声音设置”可切换男声/女声、独立调整语音与音效音量，并保存偏好。默认男声“超文”和女声“婷婷”均为离线打包资源。
- 我方操作区下方展开“胡牌条件”，查看当前不能胡的原因、发财与报嘴限制，以及未成组的牌。
- 任意玩家胡牌后，结算下方展示实际四组面子和一对将牌。
- 规则教程的四课都由真实 `GameState` 合法动作推进，不写入普通本地存档。
- 联网房间显示四个座位的在线、离线、机器人和托管状态，可复制不含密码与恢复令牌的邀请链接。
- “牌局记录”提供报嘴、碰、三类杠和胡牌的关键节点，可直接跳到动作前后。
- 教练终局会汇总本家人类出牌的整局统计与最值得复盘的前三手，反馈样本只保存在本机且不含手牌或牌山。
